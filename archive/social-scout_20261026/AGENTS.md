# 社交媒体科研侦察：隔离试运行

用户于2026-10-26明确授权仅在本目录新建规则和过程记录。根目录AGENTS.md、workflows、Raw、Wiki及其他已有文件只读；不执行Git提交、实验、训练或小红书发布、评论、点赞、收藏。

本轮问题：agent abstention究竟改变了什么，哪些线索值得下一步研究注意力。参考用户指定ChatGPT对话最后一轮；它是工作流建议，不是学术证据。

预算：最多8组不同小红书查询、12篇帖子详情；重点核查2个问题簇，代表性新旧论文最多6篇正文定向阅读，其他仅作身份/摘要导航。输出不超过4个问题簇。预算是上限，不是配额；同篇转载去重。不自动启动正式Brainstorm或AutoResearch。

流程：扫描前沿与困难 → 动态查旧术语及质疑 → 按问题聚类 → 核对原文和会议身份 → 分流 → 记录工作流有效和失效之处。

分别标注帖子说法、论文主张、原文证据、试验推断、待验证假设；图片/正文/评论/评审读取不全须明确记录。发布时间、论文版本、会议投稿/录用、社会热度分别处理；首次横截面不能证明升温趋势。

贡献区分问题、机制认识、方法、评测、系统效率、性能迭代；问题价值与证据强度分别评价。区分对用户新、对领域新、旧问题新包装。

分流：了解即可/保留观察/值得补充核查/值得brainstorm。候选需有相近工作、竞争解释、反例、下一步可区分证据；AutoResearch建议只围绕一个不确定性，附继续、改写、停止条件。

本目录只保存必要的规则、检索与核查过程，不创建正式论文页、不分配来源ID、不更新索引或日志。临时访问令牌和完整账户/评论个人信息不落盘。学术结果主要在聊天交付。
